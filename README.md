# Rage Room

<!-- Add a short description of the game here -->
A browser-based rage room game.

**Live:** https://onlinerageroom.vercel.app/

## Built with

React, TypeScript, Vite, Tailwind CSS

## Run locally

```bash
pnpm install
pnpm run dev
```

## Build

```bash
pnpm run build
pnpm run preview
```

## Deploy

Hosted on Vercel. Every push to `main` deploys automatically.
